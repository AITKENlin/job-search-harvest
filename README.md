# 40+ 求职建议 · 开源工具包（地区中立）

> **给 40 岁以上求职者的一件趁手工具。**
> 上传简历 → 自动体检 → 求职策略与岗位推荐 → 实时搜岗。**零配置、不需要任何 API key。**
> **不绑定任何城市**：你在哪座城市找工作，就写进需求里（如「上海 品牌经理」）。

---

## 为什么做这个

40 岁以后找工作，遇到的通常不是"能力不行"，而是三件事：

1. **筛选机制不认识你。** 公开招聘平台的第一道门（HR 初筛、系统关键词过滤）天然偏向年轻履历，二十年经验在简历上反而显得"贵"。
2. **信息不对称。** 真正不限年龄的通道（机关编外、国企公告、外企官网社招）散落在几十个政府网站和企业招聘页里，没人替你汇总。
3. **心气被消磨。** 投了三十份没有回音，人就容易从"在找工作"滑向"不想找工作"。

这个工具针对这三件事，分别给出：**动态简历体检 + 岗位池/渠道入口汇总 + 激励段落**。

**核心第一性原理：**

> **收入不要断 ＞ 专业对口 ＞ 薪资预期 ＞ 城市就近**

先接住现金流，再谈升级。降薪不是解法，换交易结构才是——从"被雇为总监"转向"被采购为专家/顾问"，价格由交付定，不由年龄定。

## 30 秒上手

```bash
cd webapp
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

无需注册、无需 API key、无需联网配置。默认只绑本机回环（`127.0.0.1`），简历不会离开你的电脑。

**页面上能做什么：**

| 模块 | 说明 |
|---|---|
| ① 上传简历 | 支持 PDF / DOCX / TXT，也可以直接粘贴文字 |
| ② 简短问卷 | 年龄 / 城市 / 行业 / 硬约束，**可全部留空**，能自动识别的会自动提取 |
| ③ 分析并给建议 | 激励段落 + 简历体检 + 求职策略 + Top 推荐岗 + 大厂 HR 能力对标 + 今日行动清单 |
| ④ 实时搜索岗位 | 列表逐行给出 **公司名字 / 公司属性 / 地区 / 职位名称 / 直链网址 / 投简历的邮箱** |
| ⑤ 外企官网目录 | 只列公司名与官方 careers 链接，**不编造岗位与薪资** |

## 地区中立：你在哪找工作，就写哪

**地区永远由你的输入决定**，工具不预设任何城市：

| 你的输入 | 行为 |
|---|---|
| `上海 品牌经理` | 自动识别城市＝上海 |
| `品牌经理` + 地区框填「深圳」 | 用你指定的城市 |
| `品牌经理`（没提城市） | 用 `JOB_CITY` 环境变量；没设则用样本城市兜底 |
| 未收录的城市 | **不猜网址**：只给全国通用官方渠道（人社部·中国公共招聘网 / 12333），并提示你用 AI 助手检索「某某人社局 招聘公告」 |

换默认城市：`JOB_CITY=上海 python app.py`。

## 三个渠道，零配置

页面上勾选即可，默认全选：

- **人社 / 国企官方公告** —— 唯一能稳定提供**投递邮箱**的渠道（公告里普遍附报名邮箱或报名系统）。
- **外企官网** —— 外企 HC 多走全球 EVP，社招看经验与专业能力，对年龄相对友好。
- **主流招聘平台** —— 猎聘等实时在招岗位。

> **邮箱真相（重要）**：招聘平台与多数外企本就不公开邮箱，走站内/官网系统投递。本工具**不会为了填满"邮箱"这一列而编造任何地址**——没有就如实标注"报名方式"，空白比假信息有价值。

## 目录结构

```
.
├── SKILL.md                      # 完整方法论：采集管线 / 政策核查 / 评分模型 / 避坑清单
├── scripts/
│   └── liepin_harvest.py         # 岗位采集脚本
└── webapp/                       # 可直接运行的网页版
    ├── app.py                    # Flask 入口（/analyze、/search、/search/import）
    ├── analyzer.py               # 简历分析引擎 + 激励文案生成
    ├── search.py                 # 多后端实时搜索引擎
    ├── region.py                 # 地区真相来源（城市→平台参数、本地官渠、自助提示）
    ├── positions.json            # 样本岗位池（含真实公告岗与报名方式；meta.sample_city=示例城市）
    ├── templates/index.html      # 前端（单文件，无构建步骤）
    └── tests/                    # 三套回归测试
```

**测试：**

```bash
cd webapp
python tests/smoke_search.py    # 解析、相关度、地区中立等纯函数
python tests/e2e_api.py         # 全部接口端到端
python tests/flow_audit.py      # 模拟真实用户全流程体检
```

## 设计原则

1. **帮到人 ＞ 功能强大。** 多一个配置项，就多一次放弃——所以默认零配置。
2. **不锚定任何个人、任何城市。** 结论由你自己的简历生成；仓库内不含任何真实个人姓名、公司、履历，也不绑定特定城市。
3. **不制造焦虑，只给行动。** 激励文案只基于简历里的事实说话，不空喊口号、不承诺结果；讲残酷真相时，必须同时给出今天能做完的下一步。
4. **数据纪律。** 岗位、薪资、邮箱必须有来源；推断一律标注「待核实」；未收录的城市**不猜网址**——**空着比编造好**。

## 换成你的城市 / 行业 / 人群

- **换城市**：改 `webapp/region.py` 的 `CITY_PARAMS`（城市→平台参数）+ `CITY_OFFICIAL`（该城市已核实的官方渠道），再替换 `positions.json` 并把 `meta.sample_city` 改成新城市。
- **换行业**：直接替换 `webapp/positions.json`；`search.py` 的关键词路由 `SLUG_ROUTES` 按职能划分，一般不绑定行业。
- **换人群**（如 35+、转行者）：调整 `analyzer.py` 的评分权重与 `_encourage()` 文案。
- **发布前自检**：把你的个人信息词写进 `webapp/.forbidden_terms`（每行一个，已被 `.gitignore` 忽略），`tests/flow_audit.py` 会校验页面不含这些词。
